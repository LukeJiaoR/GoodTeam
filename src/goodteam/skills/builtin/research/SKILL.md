# Evidence-Based Research

1. Read relevant files directly before forming conclusions; never invent file paths, symbols, or command outputs.
2. Cite concrete evidence (`path:line` or command output) for every key claim.
3. Explicitly list unknowns, assumptions, and open questions rather than guessing.
4. Stay strictly read-only: do not modify repository files during research tasks.

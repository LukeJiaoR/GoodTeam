# Project Memory Hygiene

1. Keep memory files concise, structured, and factual (no transient logs or duplicated code).
2. `project.md`: tech stack, entry points, key module boundaries, test commands.
3. `decisions.md`: architectural choices with rationale and date.
4. `lessons.md`: recurring pitfalls, environment quirks, and verified fixes.

# QA & Verification

1. Identify all changed behaviors, boundary cases, and error handling paths.
2. Write focused tests using existing project test conventions (`pytest` / `vitest`).
3. Execute the test suite after edits and report exact pass/fail counts without extrapolating skipped tests.

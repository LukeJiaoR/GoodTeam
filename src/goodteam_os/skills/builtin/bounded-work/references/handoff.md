# Handoff checklist
- Result and relation to the requested completion conditions.
- Evidence: original source/commit/job/artifact references and relevant freshness.
- Checks performed and observed outcomes; checks not run remain unverified.
- Partial result or error and what it prevents, without discarding successful peers.
- Remaining uncertainty, dependency or proposed next action. Suggestions do not authorize execution.

Source: GoodTeam #445 invocation contract, #686 shared feedback and delegation requirements, #696 planning attribution. This checklist does not prescribe a new result format or replace runtime enforcement.

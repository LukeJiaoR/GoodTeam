# Evidence-based research

Use this method for a delegated factual investigation. Begin with the specific question, existing evidence, scope and decision the research should inform; do not redefine the product or silently turn research into implementation.

## Investigate the gap
Inspect relevant supplied or authorized sources. Prefer original evidence for consequential claims. Identify source dates and versions when they affect applicability. Compare conflicting accounts and distinguish observations from inference. Search only when needed and supported by this invocation's authorized tools; an unavailable search capability is a specific limitation, not permission to use another provider.

## Use search without inventing evidence
Send only the query context necessary for the question, not the entire private project Context. Keep actual returned source references and available search/call attribution. No results, an unsupported tool, an error and a generated answer without a search are different outcomes. Never label generated text as retrieved evidence. Read references/evidence.md when consolidating findings.

## Return a bounded report
Answer the question with evidence and limitations. Include useful partial findings and unresolved contradictions. Explain what remains unknown and which decision it affects. Recommend further work if justified; do not convert recommendations into an approved plan or task completion. Use the original reporting contract and preserve job/task attribution.

# Review core

Inspect changes for defects, regressions, maintainability, security, test quality,
and alignment with approved artifacts. Check quality, security, performance,
tests, and contract alignment as applicable to the task.

Lead with actionable issues ordered by severity and grounded in file references.
Make observed evidence and remaining uncertainty clear. The task's explicit
requirements take precedence over this optional baseline's suggested coverage.

For additional optional lenses and report organization, see
[profile methods](references/profile-methods.md). Choose only those relevant to
the requested review; their inclusion here does not mandate all three profiles.

This package supplies methods, not permissions, workflow decisions or Runtime
support. It can be omitted or fully replaced by a user's standard Skill package.
See [NOTICE](NOTICE.md) for the first-party source attribution.

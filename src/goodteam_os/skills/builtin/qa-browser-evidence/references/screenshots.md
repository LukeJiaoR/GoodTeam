# Screenshot checklist

- Candidate and environment: record the exact revision and the target.
- Capture: wait for the result to settle. Show the selected control and the visible result together.
- Artifact: save the browser capture as a PNG. Use a distinct name for each state.
- Report: attach or link the PNG and state exactly what it demonstrates.
- Scope: report automated checks separately. Any missing screenshot leaves its browser case unverified.

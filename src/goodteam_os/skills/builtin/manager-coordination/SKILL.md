# Project coordination

Use this method to coordinate a project from its current Context. The Manager owns goals, priority, scope and continuation; professional investigation, detailed planning, implementation, testing and technical review belong to delegated Workers.

## Understand intent without imposing stages
Use existing Context to distinguish exploration from a clear request to proceed. Discuss the goal, value, use case, constraints and tradeoffs when needed. Preserve agreed points, known facts and open questions in the existing project Context so the user does not have to repeat them. Do not require discussion, search, Researcher and Planner as a universal sequence.

## Choose the next useful action
When facts are missing, delegate a bounded investigation to Researcher. When concrete decomposition is needed, delegate Planner with the agreed purpose and relevant evidence. Clearly authorized, executable work can be assigned directly. Ask the user only for a decision or input that cannot be resolved within the task. A pending question or running job does not by itself prevent reasoning about independent work.

## Delegate and follow through
Provide Role, purpose, task, relevant Context references, scope, constraints and completion conditions through the existing action contract. Do not select a permanent worker identity or promise unavailable capacity. Use returned job IDs to observe actual execution. Assignment is not proof of running work. Read references/continuation.md before interpreting results or deciding follow-up.

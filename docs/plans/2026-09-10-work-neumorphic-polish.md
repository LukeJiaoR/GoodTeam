# Work 新 UI：新拟物材质与交互精修

## 方向与边界

用户明确要求新拟物风格，整体大气、统一，有舒适的 UX 交互动画。
以 Work 新 UI 为基准，保留三栏、Assistant、执行与交付的现有产品结构。
本轮修改覆盖 Work 的三个样式文件及关联表现测试，不改变 M0 的任务草稿、运行恢复、
确认逻辑、API、持久化、依赖或旧页面。

## 设计约定

- 统一左上光源与冷灰材质。面板轻微浮起，输入和选中状态下沉。
- 阴影按面板、卡片、控件三个尺度递减，边缘仍保留可见边界。
- 页面留出外侧空间，正文、标题、时间建立稳定层级，保留 Geist 字体。
- 主操作用蓝色，运行、阻塞、完成保留各自的状态语义。
- 按压反馈快速响应，松开平滑恢复；键盘按压不产生位移。
- 导航上下文使用浮层，展开不推挤工作区；任务负责人始终可读，悬停不改行高。
- 手机沿用相同材质，触控控件保持足够高度；减少动态效果偏好关闭位移动画。
- 等待用户操作的提示保持静态；正在工作的状态灯可保留轻微呼吸。

## 验证计划

Tier 4，影响范围为浏览器布局与表现。运行前端测试、lint、build、
样式作用域检查与 `git diff --check`。在独立预览环境检查桌面、手机、
浅深色、任务展开、详情弹窗、按压和减少动态效果。
只读使用隔离 smoke 数据，不对真实项目执行任务或审批。
